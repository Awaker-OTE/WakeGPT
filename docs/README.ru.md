## Превращайте мимолётные мысли в растущие заметки

Запишите короткую мысль, выберите рабочее пространство и блокнот — WakeGPT сможет постоянно добавлять новые записи в ваш Markdown-файл. Не нужно заранее наводить порядок в папках, открывать редактор или отвлекаться от текущей задачи. Сначала сохраните мысль, а упорядочить её можно позже.

WakeGPT подходит, чтобы:

- быстро фиксировать задачи, признаки ошибок и идеи реализации во время разработки;
- собирать выводы, ссылки и снимки экрана из продуктовых обсуждений и диалогов с ИИ;
- постепенно наполнять один Markdown-файл небольшими записями;
- переносить выбранные заметки в поле ввода ChatGPT без повторного набора.

## Возможности WakeGPT

- **Быстрая запись** — Обычный текст, Markdown, ссылки и изображения, включая прямую вставку изображения из буфера обмена.
- **Постоянное дополнение Markdown** — Создайте блокнот или привяжите существующий файл `.md` из рабочего пространства, после чего новые записи будут добавляться автоматически.
- **Несколько пространств и блокнотов** — Разделяйте проекты и переключайтесь между входящими и блокнотами с помощью вкладок.
- **Гибкие форматы** — Последовательная нумерация, маркеры, списки задач и отметки времени с автоматическим пересчётом порядка после изменений.
- **Управление записями** — Просмотр, редактирование, копирование, перенос, удаление и восстановление. Изображения показываются в виде миниатюр и открываются в увеличенном виде.
- **Передача в ChatGPT** — Поместите выбранный текст и настоящие вложения-изображения в текущее поле ввода ChatGPT и проверьте их перед отправкой.
- **Локальное хранение** — По умолчанию заметки, изображения и файлы рабочего пространства остаются на компьютере. Основные функции не зависят от телеметрии.

## Три места для быстрой записи

| Интерфейс | Для чего подходит |
|---|---|
| **Приложение WakeGPT** | Управление рабочими пространствами, блокнотами, историей и настройками. |
| **Строка меню macOS** | Быстрый вызов компактной панели без переключения с текущей задачи. |
| **Боковая карточка ChatGPT** | Заметки рядом с диалогом, переключение блокнотов и перенос выбранных записей в поле ChatGPT. |

Основное приложение и быстрые панели независимо сохраняют выбранный блокнот и черновик. Переключение в одном интерфейсе не меняет неожиданно содержимое другого.

## Путь одной записи

1. Введите текст, Markdown или ссылку либо вставьте изображение.
2. Выберите входящие рабочего пространства или Markdown-блокнот.
3. Подтвердите запись, чтобы сохранить её локально; для привязанного блокнота WakeGPT также добавит её в Markdown-файл.
4. Позже запись можно изменить, перенести, удалить, восстановить или использовать в ChatGPT.

WakeGPT управляет только явно размеченными областями быстрых заметок внутри Markdown-файла. Остальную часть документа можно редактировать любым удобным инструментом.

## Состояние проекта

Сейчас WakeGPT — открытый **прототип для macOS**. [Официальный GitHub Release `v0.1.1` для macOS](https://github.com/Awaker-OTE/WakeGPT/releases/tag/v0.1.1) уже доступен для загрузки.

- Работа приложения проверена на macOS с Apple Silicon.
- `v0.1.1` — официальный GitHub Release только для macOS.
- Её Universal App Bundle содержит код для Apple Silicon и Intel, но запуск на физическом Intel Mac ещё не проверен.
- Эта версия имеет полную ad-hoc кодовую печать и включённый hardened runtime, но **не** подписана Apple Developer ID и **не** прошла нотариальную проверку Apple. Поэтому macOS может заблокировать первый запуск.
- Боковая карточка ChatGPT является экспериментальной и проверена только с точными версиями хоста, указанными в репозитории. При изменении контракта хоста она безопасно отключается.
- Поддержка Windows x64 находится в разработке, ещё не опубликована и не проверена на реальном компьютере с Windows.

Загружайте WakeGPT только из [официального GitHub Release `v0.1.1`](https://github.com/Awaker-OTE/WakeGPT/releases/tag/v0.1.1) и сверяйте SHA-256 с включённым файлом `SHA256SUMS.txt`. После первой попытки открыть WakeGPT macOS может потребовать перейти в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. См. также [инструкцию Apple](https://support.apple.com/ru-ru/guide/mac-help/mh40616/mac). WakeGPT не просит отключать Gatekeeper или удалять атрибут карантина командой `xattr`.

## Запуск из исходного кода

Потребуются Node.js, npm, Rustup и [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).

```bash
git clone https://github.com/Awaker-OTE/WakeGPT.git
cd WakeGPT/apps/desktop
npm ci
npm test
npm run tauri build
```

Сборка macOS Universal:

```bash
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm run release:macos-universal
```

Сборка из исходного кода остаётся артефактом для разработки или локальной проверки. Загружаемый пакет `v0.1.1` также не прошёл нотариальную проверку Apple, но прошёл проверки выпуска WakeGPT и опубликован с контрольными суммами и материалами о цепочке поставок.

## Конфиденциальность и безопасность

- Заметки, вложения и Markdown-файлы по умолчанию хранятся локально; телеметрия и отправка отчётов о сбоях по умолчанию отключены.
- Интеграция с ChatGPT только подготавливает содержимое поля ввода и никогда не нажимает «Отправить» за пользователя.
- WakeGPT не читает и не хранит пароли, cookie или токены входа ChatGPT.
- При удалении используется восстанавливаемая корзина WakeGPT или Корзина macOS. При конфликте операция безопасно прекращается без перезаписи изменений.

Сообщайте о проблемах безопасности приватно по инструкции в [SECURITY.md](../SECURITY.md). Не публикуйте детали уязвимостей, сведения об аккаунтах или реальные пользовательские данные в открытых Issues.
